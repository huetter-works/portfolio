# Amazon Ranking Predictor — 紹介概要

> **この Markdown は控えです。公開用は [overview.html](overview.html) を参照してください。**

コミックの**全巻セット**を扱う仕入れ判断向けに作った、Amazon ランキング予測・可視化ツールです。  
取得した BSR（Best Sellers Rank）を参考に需要の兆しを見立て、人が早く動けるようにすることを目的にしています。

---

## なぜ作ったか

全巻セットのコミックを販売しています。  
需要が一気に立ち上がると、全巻を揃えて仕入れるのは難しくなります。欠品・重版待ち・価格の乱れが重なり、後追いでは機会を逃しやすいためです。

そのため、**いち早く需要の兆しを掴みたい**と考えました。  
販売数そのものではなく、公開されている BSR の推移が予測の参考になればよい、という発想からこのプログラムを作りました。

発注数や確定売上を自動で出すツールではありません。当初は需要予測の手がかりを狙いましたが、位置づけは「何を注視するか」を早く掴むための試行です。

---

## 何をしているか

1. 日々取得した BSR の履歴を読み込む  
2. **Python** 上で **Prophet** を使い、ASIN ごとの順位推移を短期予測する  
3. 結果を **Plotly** でインタラクティブなグラフ（HTML）にする  

画面では、時系列・分布・推定 GMV の切替や、注目したい商品の絞り込みなどを試せます。  
BSR は需要センサーとして扱い、順位から換算した数値は「推定」と明示します。確認された販売数としては扱いません。

---

## デモについて

[`interactive_ranking_predictions.html`](interactive_ranking_predictions.html) は、操作確認用の**小規模サンプル**です。  
ASIN 数を絞った BSR 系列の予測グラフで、グラフの切替や絞り込みを試せます。

---

## 技術

| 項目 | 内容 |
|------|------|
| 言語 | Python |
| 予測 | Prophet（時系列） |
| 可視化 | Plotly（インタラクティブ HTML） |
| 入力 | 日次の BSR 履歴（CSV） |

紹介の中心は上記の「BSR → 予測 → グラフ」です。画面では供給状態の可視化や注目度の並べ替えなども試せます。

---

## わかったこと・限界

運用の結果、**BSR だけで需要を十分に見通すのは困難**でした。順位は需要の一端ではあるものの、それ単体では仕入れ判断を支える精度には届きにくい、という実感です。

加えて、取次経由の発注タイムラグや、出版流通における注文・入荷のばらつきがあり、**予測が得られても仕入れ成果に結びつきにくい**という実務上の制約もありました。大きな成果にはつながっていません。

そのため本ツールは「需要を当てる」ことより、業務課題をデータと可視化で検証した過程として位置づけています。

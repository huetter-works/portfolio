Amazon Ranking Predictor

コミックの全巻セットを扱っています。需要が一気に立ち上がると、全巻を揃えて仕入れるのは難しくなります。欠品や重版待ちが重なる前に、いち早く需要の兆しを掴みたい——そのために作ったのがこのツールです。

公開されている Amazon の BSR（Best Sellers Rank）の推移を参考に、需要予測の手がかりにできないかと考えました。販売数そのものではなく、順位の動きから「今、何を注視すべきか」を見やすくします。

具体的には、取得した BSR データを Python で処理し、Prophet で短期の推移を予測し、Plotly でインタラクティブなグラフにしています。発注数や確定売上を自動で出すものではありません。

運用の中で、BSR だけでは需要を十分に見通せないこと、また取次経由の発注タイムラグや出版流通の注文・入荷のばらつきにより、予測を仕入れ成果へつなげるのも難しいことが分かりました。大きな成果には結びついていませんが、業務課題をデータと可視化で検証した過程として公開しています。

デモは操作確認用の小規模サンプルです。Amazon 公式・提携のサービスではありません。

技術

  • Python
  • Prophet（時系列予測）
  • Plotly（インタラクティブ HTML）

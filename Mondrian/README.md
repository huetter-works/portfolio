# Mondrian — NEUE CSS GESTALTUNG

CSS Grid でピート・モンドリアンの画面構成（色面と黒線）を模した静的ギャラリーです。デスクトップ（560px 以上）では画面全体が1枚のコンポジションとして読み取れるよう設計しています。

## ページ

- `index.html` — ギャラリー（Grid レイアウト）
- `profile.html` — 人物紹介・年表

## 未収録の作品について

グリッド上の一部セル（例: 陽の中の風車、ウェストカペッレの灯台、線のコンポジション、赤・青・白のコンポジション II、ニューヨーク I）は画像未収録です。

これらは「欠け」ではなく、色面として構図に参加させる意図で残しています。タイトルのみのセルは、モンドリアン的な沈黙した矩形として読んでください。

## 著作権・画像について

- **ピート・モンドリアンの絵画:** 1944年没。日本を含む多くの法域ではパブリックドメインと一般に解されています。国・公表年により扱いが異なる場合があります（とくに米国）。
- **掲載画像:** 主に Wikimedia Commons 等の複製画像を利用しています。絵画がパブリックドメインでも、写真・データの利用条件はファイルごとに確認してください。
- 本サイトはポートフォリオ目的の非商用デモです。

## 技術メモ

- HTML / CSS / jQuery（モーダルとカード演出）
- 560px 未満は縦積み、以上は Grid + カードフリップ
- `prefers-reduced-motion: reduce` では回転系アニメを抑止します

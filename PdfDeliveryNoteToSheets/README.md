# 送品票 OCR → Google Sheets（紹介）

スキャンした送品票 PDF を OCR で読み取り、Google スプレッドシートへ載せる処理を半自動化するツールの**紹介ページ**です。  
業務時間外の個人開発プロトタイプで、実用化には至っていません。動く一式は公開せず、説明とマスク済みスクリーンショットのみ掲載しています。

公開 URL: https://huetter-works.github.io/portfolio/PdfDeliveryNoteToSheets/

## 掲載内容

- `index.html` … 紹介文と画面イメージ
- `images/` … HITL メニュー／ROI オーバーレイ（正味・掛率が分かる数値はマスク）

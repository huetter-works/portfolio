# 楽天商品説明文変換ツール（紹介）

楽天市場向けの商品説明 HTML を、店舗テンプレートに合わせて生成するブラウザツールの**紹介ページ**です。  
動く一式は公開せず、説明文とスクリーンショットのみ掲載しています。

公開 URL: https://huetter-works.github.io/portfolio/RakutenDescriptionTool/

## 掲載内容

- `index.html` … 紹介文と画面イメージ
- `images/` … 入力／プレビュー／HTML 出力のスクリーンショット

## 注意

- スクリーンショット内の店舗名・商品はデモ用の架空データです
- 楽天公式・提携ではありません
